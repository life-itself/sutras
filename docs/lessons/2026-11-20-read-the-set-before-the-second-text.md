# Read the editions as a set before writing the next one

Date: 2026-11-20. Track: editorial.

Eight introductions written by eight agents from the same brief drifted in a dozen small ways nobody saw one page at a time: word counts against reading times, "forty-eight" against "48", "Hui Neng" against "Hui-neng", five pages ending "they can wait for a second reading", one page retelling the translator's introduction in his register, a copied typo in a name. Each page had passed its own critique.

**Lesson:** after the second edition, read all of them in one sitting and write the shape down (now `docs/guides/writing-an-introduction.md`) before a third agent starts. Give the critic the set, not the page; set-level drift is invisible from inside one text.
