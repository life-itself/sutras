# A brief must pass its own rules before anyone builds to it

Date: 2026-11-20. Track: landing (the landing page brief).

The first draft of the landing brief named an opening line as its choice, then forbade exactly that kind of line in the "must not" list (a teacher's words, set apart). It attributed its four promises to `vision.md`, where they are not, and its reading-time rule said the figures stay off the page while the page showed them. A fresh critic caught all three in one pass.

- After choosing an option, check it against every "must not" and every done-check line, one by one.
- Quote a source only after reading the line in that source; name the file that holds it.
- A rule that says where a figure lives must match what is built. Compute figures by script and put the method next to them.
