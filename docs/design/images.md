Files live in `assets/images/<slug>.jpg`, each under 150 KB, made from the sources below with `docs/design/directions/` tooling (downscaled JPEGs, a crop where noted). Credit appears on each text's page in the figure caption. Chosen for beauty and for a real link to the text; where nothing fits honestly, a text has no image (none yet in that case).
