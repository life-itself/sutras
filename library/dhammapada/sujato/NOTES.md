## Files

Sujato is kept as a parallel translation (CC0) for a later side-by-side view; the chosen translation is Thanissaro Bhikkhu's (Rufus, 2026-11-20), in `../NOTES.md`. Paths below are relative to this folder.

All are JSON objects keyed by segment ID, e.g. `dhp1:1` is verse 1, line 1; `dhp1:0.3` is a heading. The four sets share keys, so translation, Pāli and notes line up.

- `translation/` — `translation/en/sujato/sutta/kn/dhp/dhpN-M_translation-en-sujato.json` (26 files, one per chapter).
- `root/` — Pāli, `root/pli/ms/sutta/kn/dhp/dhpN-M_root-pli-ms.json` (26 files).
- `html/` — the HTML template per segment, `html/pli/ms/sutta/kn/dhp/dhpN-M_html.json` (26 files).
- `comment/` — Sujato's notes, `comment/en/sujato/sutta/kn/dhp/dhpN-M_comment-en-sujato.json` (12 files; the other 14 chapters have no notes file).

## Citation

Verses are numbered 1–423 straight through the book (not per chapter), so `/dhammapada#183` is verse 183. Chapters (vaggas) are 1–26.
